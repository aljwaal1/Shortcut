# Shortcut 0.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade Shortcut 0.4 with advanced app-usage statistics, persistent execution history, favorite/recent tools, and higher-quality image/PDF workflows while keeping all data local and permissions contextual.

**Architecture:** Extend existing modules instead of replacing them. Keep bounded local persistence in SharedPreferences/JSON, isolate pure calculation/state logic for unit testing, and use Compose for new dashboards while preserving current activities and tool routing.

**Tech Stack:** Kotlin, Jetpack Compose, Android UsageStatsManager, SharedPreferences/JSON, existing Material3 UI, existing GitHub Actions strict Android CI.

**Spec:** `docs/superpowers/specs/2026-09-16-usage-history-favorites-media-design.md`

## Global Constraints

- All user data remains local; no account or cloud service.
- No Accessibility service.
- No broad storage permission; use Android file pickers / MediaStore / app-owned files.
- Usage Access is requested only when enabling usage statistics.
- Notifications/exact alarms/location/MediaProjection are requested only by the feature that needs them.
- History keeps at most 200 records.
- Recent tools keep at most 8 unique tools.
- Crop remains single-image.
- Final verification command: `gradle :app:testDebugUnitTest :app:lintDebug :app:compileDebugAndroidTestKotlin :app:assembleDebug --stacktrace`.
